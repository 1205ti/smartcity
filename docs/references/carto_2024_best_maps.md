# CARTO — 2024 Best Maps & Dataviz

원문: https://carto.com/blog/2024-best-maps-dataviz/ (2026-09-14 수집)

CARTO가 꼽은 2024년 지도·데이터시각화 사례 24개. 아래는 요약이며,
실제 지도는 링크를 열어야 인터랙션을 볼 수 있다.

## 글이 짚은 세 가지 흐름

1. **데이터 규모와 속도** — H3 공간 인덱스와 동적 타일로 수백만 피처를 렌더링하고,
   실시간 API로 지도를 살아 있게 만든다.
2. **접근성** — SQL 매개변수, 노코드 워크플로, 생성형 AI 설명으로 비전문가도 직접 탐색한다.
3. **고급 분석** — 공간-시간 핫스팟, 경로 최적화, 지리적 세분화 같은 방법론이 일반화됐다.

정리하면 **사용자 중심성 · 확장성 · 해석 가능성** 셋이 축이다.

## 우리 프로젝트에 바로 쓸 만한 것

- **4번 홍수위험** — 색 강도로 위험도를 깔고 건물 단위로 파고드는 구조.
  관악 수문 주제에 그대로 대응된다.
- **17번 존 스노우** — 단순한 점 지도 하나로 인과를 드러낸 사례. 시각적 서사의 원형.
- **21번 핫스팟 대비** — 원자료를 그냥 뿌린 지도와 핫스팟 분석 결과를 나란히 보여 준다.
